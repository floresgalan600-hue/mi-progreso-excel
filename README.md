# Mi progreso — Excel intermedio

Aplicación web estática para el seguimiento de 12 actividades de aprendizaje y 14 indicadores KPI.

## Uso
Abre `index.html`, registra horas en Mis prácticas, ejercicios en Plan de estudio y entregables en Resultados. Los datos quedan guardados en el navegador mediante localStorage. Para pasarlos entre dispositivos, usa Exportar/Importar en Ajustes.

## Publicación en Render
Conecta este repositorio en Render como **Static Site**, con build command `echo Ready` y publish directory `.`. También puedes usar el archivo `render.yaml` como Blueprint.

## Aviso
La información no se sincroniza automáticamente entre dispositivos: no hay backend ni inicio de sesión.
